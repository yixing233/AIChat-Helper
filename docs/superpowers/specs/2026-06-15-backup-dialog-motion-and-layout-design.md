# 备份库弹窗动效与版本管理排版设计

## 目标

优化备份库中各类对话框的打开与关闭体验，并修复历史版本管理弹窗在长标题、时间和摘要共存时的文本挤压与错位问题。

## 方案

1. 统一弹窗动效
   - 遮罩层使用更柔和的淡入淡出。
   - 内容层使用轻微上浮与缩放的进入动画，关闭时反向执行。
   - 图片预览、文本预览、删除确认、版本管理沿用同一套节奏，减少不同弹窗之间的割裂感。

2. 优化版本管理文本布局
   - 列表项维持“勾选区 + 文本区”的双列结构。
   - 文本区顶部改为 `minmax(0, 1fr) auto`，保证标题能在剩余空间内稳定截断，时间信息固定在右侧。
   - 元信息与摘要分别控制换行与截断，避免长文本把整行撑坏。

## 影响范围

- `extension/src/popup/styles.css`
- `extension/src/popup/backup-library.ts`
- `extension/src/__tests__/backup-library.test.ts`
